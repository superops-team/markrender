# 导出菜单显示问题修复报告

## 🎯 问题描述

**用户反馈**: "导出按钮只能展示第一个导出项，其他选项不显示"

**问题现象**: 
- 点击导出按钮后，菜单只显示第一个"导出 HTML"选项
- 其他三个选项（Markdown、PDF、EPUB）不可见
- 菜单整体过于紧凑，无法容纳所有选项

## 🔍 问题根因分析

通过专门的诊断脚本分析发现：

### 原始问题数据
- **菜单尺寸**: 119×114px（过小）
- **菜单最小宽度**: 80px（过窄）
- **菜单项内边距**: 4px 8px（过小）
- **菜单项高度**: 未设置最小高度
- **菜单整体内边距**: 4px（过小）

### 根本原因
1. **菜单尺寸不足**: 80px的最小宽度和缺少最小高度设置，导致菜单无法容纳4个选项
2. **内边距过小**: 4px的内边距导致菜单项显示拥挤
3. **缺少高度限制**: 没有设置菜单项的最小高度，可能导致文本被压缩

## ✅ 修复方案

### 修复的CSS样式
**文件**: `app/preference/style_utils.py` - `create_toolbar_menu_style()`

**修复前**:
```css
QMenu {
    background-color: #FFFFFF;
    border: 1px solid #EBEEF2;
    border-radius: 4px;
    padding: 4px;           /* ❌ 过小 */
    min-width: 80px;        /* ❌ 过窄 */
    /* ❌ 缺少最小高度 */
}
QMenu::item {
    color: #4D5358;
    padding: 4px 8px;       /* ❌ 过小 */
    margin: 1px;
    border-radius: 4px;
    font-size: 13px;
    /* ❌ 缺少最小高度 */
}
```

**修复后**:
```css
QMenu {
    background-color: #FFFFFF;
    border: 1px solid #EBEEF2;
    border-radius: 4px;
    padding: 6px;           /* ✅ 增加50% */
    min-width: 120px;       /* ✅ 增加50% */
    min-height: 120px;      /* ✅ 新增最小高度 */
}
QMenu::item {
    color: #4D5358;
    padding: 8px 12px;      /* ✅ 增加100%/50% */
    margin: 2px;            /* ✅ 增加100% */
    border-radius: 4px;
    font-size: 13px;
    min-height: 20px;       /* ✅ 新增最小高度 */
}
```

### 修复效果对比

| 属性 | 修复前 | 修复后 | 改进幅度 |
|------|--------|--------|----------|
| **菜单最小宽度** | 80px | 120px | +50% |
| **菜单最小高度** | 未设置 | 120px | 新增 |
| **菜单内边距** | 4px | 6px | +50% |
| **菜单项内边距** | 4px 8px | 8px 12px | +100%/+50% |
| **菜单项边距** | 1px | 2px | +100% |
| **菜单项最小高度** | 未设置 | 20px | 新增 |
